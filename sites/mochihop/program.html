見学・無料体験のご予約

PROGRAM

療育プログラム

あそびの中に、療育のねらいを。
ねらいの中に、こどもの笑顔を。

  1. トップ
  2. 療育プログラム

プログラムは、保育士・児童指導員と専門職がいっしょに組み立てています。
ひとりひとりの個別支援計画の目標に合わせて、組み合わせや難しさを毎回調整します。

PROGRAM 01

あそびラボ

つくって、こわして、またつくる。

新聞紙、粘土、段ボール、落ち葉。毎回ちがう素材を用意して、手と頭をいっしょに動かします。完成させることよりも、「どうしてこうなったんだろう」と考えている途中の時間を大切にしています。思いどおりにならなくて怒ってしまう日も、気持ちを落ち着ける練習のチャンスです。

このプログラムのねらい

  • 手指の操作
  • 試してみる力
  • 集中して取り組む
  • 順番を待つ
PROGRAM 02

ことばタイム

「伝わった！」を、たくさん。

絵カード、ジェスチャー、短い言葉。その子がいちばん使いやすい方法で、気持ちを伝える練習をします。スタッフとの1対1から始めて、少しずつ友だちとのやりとりへ。言語聴覚士が、発音や聞きとりの様子もあわせて見ていきます。

このプログラムのねらい

  • 要求を伝える
  • あいさつ
  • 気持ちのことば
  • 友だちとのやりとり
PROGRAM 03

リズムパーク

音を聴いて、待って、たたく。

太鼓、鈴、手拍子。合図を聴いてから音を出す、合図で止まる。音楽のあそびの中で、聴く力と待つ力を育てます。みんなで同じリズムをそろえる体験は、集団の中にいる心地よさにもつながります。

このプログラムのねらい

  • 聴く力
  • 待つ力
  • まねをする
  • 集団への参加
PROGRAM 04

からだチャレンジ

体の真ん中から、ととのえる。

走る、跳ぶ、ぶら下がる、バランスをとる。理学療法士と作業療法士がプログラムを組み、遊びながら体幹と姿勢をととのえます。座っていられる時間が延びたり、鉛筆が持ちやすくなったり。体の変化は、教室での過ごしやすさにもつながります。

このプログラムのねらい

  • 体幹
  • バランス
  • 力の加減
  • 体のイメージ

ONE DAY

1日の過ごし方

SEED

児童発達支援未就学のこども

  1. 10:00
    登所・朝の会歌で「おはよう」。今日の予定を絵カードで確かめます
  2. 10:30
    設定あそびあそびラボ、リズムパークなど日替わりのプログラム
  3. 11:30
    自由あそび好きなあそびを選んで、友だちとのやりとりも練習
  4. 12:00
    昼食持ってきたお弁当を、みんなでいただきます
  5. 13:00
    からだチャレンジマットやトランポリンで、体を動かします
  6. 13:40
    帰りの会・お迎え今日できたことを、保護者の方にお伝えします
STEP

放課後等デイサービス学校がある日

  1. 14:30
    学校へお迎えスタッフが車で学校まで迎えに行きます
  2. 15:15
    到着・おやつ手洗いとうがいをして、ひと休み
  3. 15:45
    宿題の時間わからないところは、スタッフといっしょに
  4. 16:30
    プログラム外あそび、ことばタイム、調理など曜日ごとに
  5. 17:30
    帰りの会今日のふりかえりと、明日の予定の確認
  6. 18:00
    ご自宅へ送迎順番にご自宅までお送りします

※ 時間は一例です。事業所や曜日によって変わります。学校が休みの日のSTEPは 9:00〜17:00 で、季節のおでかけも行います。
